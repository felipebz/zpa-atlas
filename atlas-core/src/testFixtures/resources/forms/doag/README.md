# Doag Forms demos

`demo0002_fmb.xml`, `demo0004_fmb.xml` and `modernize_fmb.xml` are `frmf2xml` exports of forms of the DOAG Forms
demos. The original sources are in https://github.com/Doag/Forms/tree/849acc3ad1dcca3d51ac7627783f556674f13001/demos.
